端点 = 一个 API 的 URL + Key。定义好端点后，可在"槽位/模型"页绑定给哨兵、记忆 digest、ASR 或主脑使用。
槽位：后台专用调用（哨兵、记忆、语音、桌面化身轨迹与生图）。选错端点会导致功能失败，页面顶部会弹 toast 提示。
哨兵（sentinel）
分析传感器/日程数据，决定何时主动联系你。
记忆 digest（memory_digest）
即时检索路由、聊天状态提取、手动总结新记忆。
语音识别（asr）
唤醒词和通话中的语音转文字。仅支持 openai 类型端点。
桌面化身轨迹（presence_renderer）
把自然语言出现意图翻译成严格轨迹。留空时 fail-closed，opportunity 不会看到出现能力。
桌面化身生图（presence_image）
只在主动扩充形象库时调用；默认直连 Gemini Nano Banana 2，随后仍由本地 rembg 抠图并严格校验透明 PNG。支持 gemini 或兼容旧生图接口的 openai 端点。
用户自定义主脑模型
定义一个 key，指向"端点 + 模型名"，聊天页模型下拉会出现。只有端点和模型都确认支持原生音频输入时才勾选；未勾选会明确拒绝语音，不会退回转写冒充听见。
