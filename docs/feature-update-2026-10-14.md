# 2026-10-14 功能更新

版本：`v2026.10.14`。本次同步 2026-09-13 之后的相伴、小剧场、心作和聊天改进。

## 一起待会儿

从聊天入口发起相伴，Android 客户端提供独立会话页面。双方可以继续说话，并在授权后按需查看手机屏幕或摄像头画面。会话支持暂停、切换来源、切换模型和结束；结束后，近期对话会接回普通聊天。

相伴默认关闭。在已登录的实例中，通过 `PUT /api/together/config` 提交 `{"enabled": true}` 开启。模型需要支持图片输入；使用语音输入前，先在设置中配置 ASR 槽位。发起会话后，手机会显示相应授权界面。相伴期间，聊天与自主轮次共享会话占用状态。

旧版手机单次截图入口已退役。电脑的单次屏幕请求仍保留。

## 小剧场与设备联动

首页增加小剧场入口。场景使用独立会话、卡片和设备编排；Core 表达动作意图，编译器生成设备程序，Android 客户端负责播放并回报实际采用的输出。会话可以暂停、继续、结束，并留下回顾与反馈。

小剧场默认关闭，初始配置只有模拟设备。先在设置中配置场景编译器槽位 `scene_compiler`，再从小剧场设置中启用并选择设备。真实设备需要 Android 蓝牙连接，软件模拟适合先检查会话与编排。

当前提供 Muse、SOSEXY、SK30、SK40 和 CX492B 的适配。各设备的通道和取值范围分别定义；广播型设备的反馈表示手机采用了程序，不代表收到物理执行回执。设备范围见 [`hardware.py`](../obsidian-chat/app/scenes/hardware.py)。

## 心语与心作

心语页面增加分类标签。普通心语保留轻量文字形式，心作支持封面、正文和图片，可在创作过程中恢复，并在完成后进入归档。聊天可以引用已发布心作，把实际文字和图片带回当前上下文。

心作来自已有自主轮次中的创作意图。创作和图片工具可能增加模型调用，使用的型号由当前模型与工具槽位决定；源码更新不会写入私人实例的端点、密钥或模型列表。

## 聊天与记忆

- 支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]` 公式。KaTeX 与字体随源码提供，首次遇到公式时加载；未完成或无效公式保留可读原文，复制与编辑保留消息源码。
- 长对话复用未变化的消息节点，流式显示和异步公式渲染保留阅读位置。后台页面暂停相关显示工作。
- 普通聊天可按需进行一次记忆或联网查询，再由 Core 在同一轮继续回复。历史 Pending Recall 账本保留，普通聊天停止创建新的异步召回。
- 模型与槽位的思考开关、强度和预算按端点支持范围校验。默认设置继续交给上游模型决定。
- 模型连接复用，实时查询 embedding 使用有界等待；空回复和过滤截断有独立状态与恢复路径。

记忆整理代码也随本次同步：AI Notes 去重采用归档，记忆压缩保留原文和回退记录。压缩默认关闭，维护入口分别是 [`dedupe_ai_notes.py`](../obsidian-chat/scripts/dedupe_ai_notes.py) 和 [`compact_memories.py`](../obsidian-chat/scripts/compact_memories.py)。规划、判断和压缩可能调用配置中的模型，需要按实际使用管理费用。

## 升级

1. 停止实例，并按[工程更新说明](engineering-update-2026-09-05.md)备份运行数据和设置。
2. 更新至 `v2026.10.14`，按 README 安装已锁定依赖，或重新构建 Docker 镜像。
3. 启动后端，刷新 Web/PWA；Android 使用同版本源码重新构建并安装。
4. 核对原有聊天和设置，再按需启用相伴或小剧场。已有自定义配置继续保留。

数据库初始化会补齐新表和字段。回退源码前，应停止实例并恢复升级前备份，使数据库与代码版本匹配。部署脚本会保留当前与上一版镜像，并清理超过保留数量的项目部署备份。

公开版本继续默认直连 Gemini，代理通过环境变量或端点配置显式启用。部署主机使用示例默认值，运行数据、APK、依赖 wheel 和私人研究记录继续留在版本库之外。
